02 / THE AI LAYER

The AI is the
policy gate.

It does not hold a wallet and it does not move money. It reads the requested workload against the exact Akash acceptable-use policy, then supplies evidence for a deterministic decision.

01 READ THE REQUEST

Understand the workload.

The model receives the service name, workload description, SDL, operator declaration, and the policy retrieved from Akash.

02 PROPOSE EVIDENCE

Find conflicts or gaps.

It returns policy conflicts, missing information, confidence, and a short rationale. Uncertainty is visible instead of being silently approved.

03 APPLY THE RULE

Let code decide.

Deterministic rules apply the confidence threshold and refuse or request information when the evidence is not strong enough.

THE GUARANTEEAI proposes. Rules decide. Proof gates settlement.

The provider must still deliver a reachable workload. BOT Chain only releases the provider-side path after the recorded proof checks pass.
