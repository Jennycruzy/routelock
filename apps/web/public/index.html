4. Rule on a real carbon credit

The obligation RouteLock tokenises here is not the credit — the credit is already a real-world asset in a registry. It is the obligation to retire one, which is the unenforceable part: offsets sold at checkout are paid for immediately and retired later, in bulk, if at all. The inventory below is read live from the Klima x402 endpoint, which needs no API key and no account. Pricing and discovery cost nothing; nothing on this page can spend or retire.

5. Replay any decision on chain

ActivationRegistry stores five commitments, the engine version, the verdict and the attempt count — and no plaintext, ever. Enter a token id to read what the chain holds. Every response carries the cast command that reproduces it without this server.

What this page does not do

Stated here rather than discovered later, because a demo that overstates itself is worse than a smaller one that does not.

  • Nothing here signs anything. This server holds no key. Minting, committing a decision and retiring a credit are operator actions run from a terminal, each with its own explicit opt-in.
  • A ruling you request is not committed on chain. Writing to the registry needs COMPLIANCE_ROLE, held by a key this process does not have. The decisions that are on chain are readable in section 5.
  • Model calls are capped and rate limited, from a ledger separate from the operator's. When the cap is reached this API answers 402 and says so rather than quietly degrading.
